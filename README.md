# 交易信号监控系统使用说明

## 系统概述

基于K线形态识别的加密货币交易信号自动监控与提醒系统，**专为7x24小时加密市场优化**，支持8种经典K线形态的自动检测，多周期并行监控，多交易所自动降级，通过飞书消息、桌面弹窗、网页仪表盘三种方式进行提醒。

## 核心特性

- 🔄 **双周期监控**：1小时 + 4小时独立运行，各有独立的扫描节奏和去重机制
- 📊 **8种形态识别**：4种看涨 + 4种看跌，针对加密市场无跳空特点做了适配优化
- 🛡️ **多交易所降级**：币安为主数据源，Gate.io为备用，自动切换确保稳定
- 📱 **三种提醒方式**：飞书推送 + 桌面弹窗 + 网页仪表盘
- 🎯 **智能去重**：各周期独立去重，避免重复打扰
- ⏰ **定时扫描**：1小时每小时55分扫描，4小时固定时间点扫描

## 支持的K线形态（加密市场适配版）

针对加密市场7x24连续交易、无跳空缺口的特点，所有形态均做了适配优化。

### 看涨形态（4种）

| 形态名称 | K线数量 | 特征说明 |
|---------|--------|---------|
| 锤子线 | 1根 | 长下影线小实体，短期低点反转信号 |
| 看涨吞没 | 2根 | 阳线实体完全覆盖前阴线实体，力度≥1.2倍 |
| 刺透形态 | 2根 | 阳线收盘深入阴线实体内部50%+（简化版，无跳空要求） |
| 早晨之星 | 3根 | 长阴+星线+长阳，底部反转形态（适配版，星线位于实体下半区） |

### 看跌形态（4种）

| 形态名称 | K线数量 | 特征说明 |
|---------|--------|---------|
| 流星线 | 1根 | 长上影线小实体，短期高点反转信号 |
| 看跌吞没 | 2根 | 阴线实体完全覆盖前阳线实体，力度≥1.2倍 |
| 乌云盖顶 | 2根 | 阴线收盘深入阳线实体内部50%+（简化版，无跳空要求） |
| 黄昏之星 | 3根 | 长阳+星线+长阴，顶部反转形态（适配版，星线位于实体上半区） |

## 快速开始

### 1. 安装依赖

```bash
cd crypto-signal-monitor
pip install -r requirements.txt
```

### 2. 配置监控列表

编辑 `config.py` 文件，修改监控交易对：

```python
WATCHLIST = [
    'BTC/USDT',      # 比特币
    'ETH/USDT',      # 以太坊
    'SOL/USDT',      # Solana
    'SNDKB/USDT',    # 闪迪（美股代币）
    'SKHYB/USDT',    # SK海力士（韩股代币）
    'XAUT/USDT',     # Tether黄金
    'MUB/USDT',      # 美光科技（美股代币）
]
```

### 3. 配置扫描周期

系统默认开启双周期监控，可在 `config.py` 的 `TIMEFRAME_CONFIGS` 中调整：

```python
TIMEFRAME_CONFIGS = {
    '1h': {
        'enabled': True,
        'label': '1小时',
        'scan_mode': 'cron',
        'cron_expr': '55 * * * *',     # 每小时第55分钟
        'deduplication_minutes': 60,    # 去重窗口60分钟
    },
    '4h': {
        'enabled': True,
        'label': '4小时',
        'scan_mode': 'fixed',
        'fixed_times': ['08:00', '12:00', '20:00'],  # 每天三个时间点
        'deduplication_minutes': 240,   # 去重窗口240分钟
        'pre_scan_reminder_minutes': 15,  # 提前15分钟预备提醒
    },
}
```

### 4. 配置飞书推送（可选）

1. 在飞书群设置 → 群机器人 → 添加「自定义机器人」
2. 复制 Webhook 地址
3. 在 `config.py` 中填入：

```python
FEISHU_WEBHOOK_URL = 'https://open.feishu.cn/open-apis/bot/v2/hook/你的地址'
```

### 5. 启动系统

```bash
python run.py
```

### 6. 访问网页仪表盘

启动后在浏览器中打开：

```
http://localhost:5000
```

## 多交易所数据源配置

系统支持多交易所自动降级，主数据源失败时自动切换到备用源。

### 数据源优先级

| 优先级 | 交易所 | 支持交易对 | 说明 |
|--------|--------|-----------|------|
| 🥇 主数据源 | 币安 (Binance) | 全部7个 | 默认使用，数据最全 |
| 🥈 备用数据源 | Gate.io | BTC/ETH/SOL/XAUT | 币安挂了自动顶上 |

### 降级策略

- **交易所级失败**（网络超时、500错误等）：整个交易所冷却5分钟，所有交易对切到下一个
- **交易对级失败**（该交易所没有这个交易对）：仅该交易对冷却1小时，不影响其他
- 每个交易对记住上次成功的交易所，下次优先使用

### 添加更多交易所

在 `config.py` 的 `EXCHANGE_LIST` 中添加：

```python
EXCHANGE_LIST = [
    {'id': 'binance', 'name': '币安', ...},
    {'id': 'gate', 'name': 'Gate.io', ...},
    {'id': 'okx', 'name': '欧易', ...},   # 想加就加，支持所有ccxt交易所
]
```

## 形态识别参数详解

所有参数均可在 `config.py` 中调整，控制形态识别的灵敏度。

### 基础参数

| 参数 | 默认值 | 含义 |
|------|--------|------|
| `PATTERN_CONFIRMATION_RATIO` | 0.5 | 实体深入比例（刺透/乌云盖顶/晨星/暮星的确认深度） |
| `SMALL_BODY_RATIO` | 0.35 | 小实体判定：实体/全振幅 ≤ 35% 算小实体 |
| `LONG_WICK_RATIO` | 2.0 | 长影线判定：影线长度 ≥ 实体的2倍 |

### 力度参数

| 参数 | 默认值 | 含义 |
|------|--------|------|
| `ENGULFING_STRENGTH_RATIO` | 1.2 | 吞没形态第二根实体 / 第一根实体的最小倍数 |
| `LONG_BODY_RATIO` | 1.5 | 长实体判定：相对近期10根平均实体的倍数 |
| `STAR_REVERSAL_RATIO` | 2.0 | 星线形态第三根实体 / 星线实体的最小倍数 |

### 位置参数

| 参数 | 默认值 | 含义 |
|------|--------|------|
| `SWING_LOOKBACK` | 5 | 锤子线/流星线的短期高低点判断窗口（K线根数） |

## 去重机制

- **按周期独立去重**：1小时和4小时的信号互不影响
- **去重 key**：`{周期}_{交易对}_{形态名}`
- **去重窗口**：1小时=60分钟，4小时=240分钟
- 去重状态保存在内存中，程序重启后会重置

## 三种提醒方式说明

### 1. 飞书消息推送
- 实时推送信号到飞书群
- 看涨=绿色卡片 / 看跌=红色卡片 / 汇总=紫色卡片
- 支持签名校验
- 包含形态名称、方向、价格、周期、时间等详细信息

### 2. 桌面弹窗
- Windows 桌面通知
- 适合坐在电脑前时即时提醒
- 检测到信号时弹出

### 3. 网页仪表盘
- 实时查看所有周期的信号
- 多周期切换（全部 / 1小时 / 4小时）
- 周期状态卡片（扫描次数、信号数、上次扫描时间）
- 监控列表一览，各周期信号状态指示灯
- 支持手动触发扫描（单周期 / 全部）
- 每30秒自动刷新

## 常见问题

**Q: 为什么检测不到信号？**
A: K线形态信号出现频率不高，4小时周期可能几天才出现一次。1小时周期会更频繁一些。可以尝试缩短周期或增加监控的交易对数量。

**Q: 为什么形态去掉了跳空要求？**
A: 加密市场7x24小时连续交易，K线之间首尾相连，几乎不存在跳空缺口。传统形态中的跳空条件在加密市场中极难触发，因此做了适配优化，用"实体相对位置+力度"替代。

**Q: 如何添加更多形态？**
A: 在 `pattern_detector.py` 中添加新的检测函数，然后在 `PATTERN_REGISTRY` 中注册，并在 `config.py` 的 `ENABLED_PATTERNS` 中启用。

**Q: 信号会重复提醒吗？**
A: 不会。系统内置去重机制，同一交易对的同一形态在同一周期的去重窗口内只提醒一次。

**Q: 币安挂了会怎样？**
A: 系统会自动降级到 Gate.io。BTC/ETH/SOL/XAUT 在两个交易所都有，降级不受影响；股票代币（SNDKB/SKHYB/MUB）只有币安有，降级后暂时没有数据。

**Q: 可以监控股票吗？**
A: 当前通过币安的股票代币（SNDKB/SKHYB/MUB等）间接监控美股和韩股。如果需要直接监控A股，需要更换数据源（如Tushare、AKShare等）。
